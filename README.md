# 🌙 Lua Projects

Coleção de pequenos projetos desenvolvidos em **Lua** com o objetivo de praticar a linguagem e desenvolver cada vez mais familiaridade com seus recursos.

Os projetos começaram com aplicações simples e foram evoluindo para trabalhar com diferentes conceitos, como tabelas, funções, estruturas de repetição, entrada de dados e manipulação de arquivos.

---

## 📂 Projetos

| Projeto | Descrição |
|---|---|
| `Phonebook` | Agenda de contatos desenvolvida em Lua, permitindo adicionar, listar, buscar e remover contatos. |
| `ForkGame` | Pequeno jogo desenvolvido em Lua, focado na utilização de estruturas condicionais, funções e interação com o jogador. |
| `TaskManager` | Gerenciador de tarefas pelo terminal, permitindo adicionar, listar, concluir e remover tarefas, além de salvar os dados em arquivo. |
